# 📚 Аудит рас классических WCS-серверов (база для AETHERION)

> Составлено на основе знания жанра: War3FT (CS 1.6), WCS (Source/CS:GO),
> «Мир Героев», BlackStar/StarServ. Цель — понять ПАТТЕРНЫ баланса и
> разнообразия, чтобы спроектировать свои расы осмысленно.

## 1. КОРНЕВЫЕ РАСЫ War3FT (эталон баланса жанра)
| Раса | Навык 1 | Навык 2 | Навык 3 | Ультимейт | Роль |
|------|---------|---------|---------|-----------|------|
| Orc | Critical Strike (шанс x2 урон) | Reincarnation (возрождение) | Mirror Image | Chain Lightning | агрессия |
| Undead | Vampiric Aura (вамп) | Unholy Aura (скорость) | Levitation | Suicide Bomber | сустейн |
| Human | Devotion Aura (+HP) | Invisibility | Teleport | Mass Teleport | утилити |
| Night Elf | Evasion (уворот) | Thorns Aura (отражение) | Trueshot (+урон) | Entangle Roots (корни) | контроль |
| Blademaster | Critical | Bladestorm | Wind Walk | — | дуэлянт |

**ВЫВОД по балансу War3FT:**
- У каждой расы 3 пассивки/актива + 1 ульта.
- Навыки качаются по 4–8 уровней.
- Архетипы: агрессия / сустейн / утилити / контроль / мобильность.
- Баланс = ни одна раса не доминирует во всём; сильна в своей нише.

## 2. РАСШИРЕНИЕ «Мир Героев» / CS:GO (масштаб + power-fantasy)
Паттерны, которые сделали жанр залипательным:
- **Дивизионы:** расы сгруппированы по силе. Чем выше дивизион — тем эпичнее.
- **Power-фантазия топ-рас:**
  - *Пудж* — крюк, притягивает врага (контроль + бурст)
  - *Терминатор* — много HP, тяжёлое оружие, регенерация
  - *Вертолёт* — полёт + ракеты + вампирка (зональный доминатор)
  - *Дуэлянт* — только Deagle + ульта-платформа (изоляция 1v1) + аим-ассист
  - *Ниндзя* — телепорт за спину, уворот, скрытность
  - *Ворона/Курица* — мобильность/полёт, трудно попасть
  - *Строитель* — постройки на карте (стены/турели)
  - *Бог с тотемами хила* — ставит тотемы, лечащие команду
  - *Архангел с тотемами урона* — тотемы, бьющие врагов
  - *Рандом-раса* — ульта даёт случайные статы (азарт/мемы)
  - *Раса с 4-5 ультимейтами рандомно* — реиграбельность
- **Гильд-расы:** эксклюзив за командную активность.

## 3. ПАТТЕРНЫ БАЛАНСА (что копируем правильно)
1. **Нет имбы на старте** — D1 расы ~равны, у каждой 1 фишка.
2. **Сила растёт с дивизионом** — D3 расы заведомо мощнее, но и качать дольше.
3. **Каждая раса сильна в НИШЕ, а не во всём** (контроль / бурст / сустейн / мобильность / зона / поддержка).
4. **Контрплей** — против телепорта есть зона, против тотемов — их можно ломать и т.д.
5. **Кулдауны ультимейтов** = главный рычаг баланса топ-рас.
6. **Раздельные сервера по дивизионам** — топ-имбы не убивают новичков.

## 4. ОШИБКИ старых серверов (НЕ повторяем)
- Свалка из тысяч несбалансированных рас → у нас тиро-структура + лор.
- «Шанс на эффект» как единственная механика → у нас ресурс «Эфир» + комбо стихий.
- Pay-to-win донат-расы → у нас донат = косметика/ускорение, не сила.
- Гринд «в стол» → у нас сезоны/Paragon/ачивки дают смысл.
