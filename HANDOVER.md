## 0. ЧТО ЭТО ЗА ПРОЕКТ (в двух словах)
==================================================================
AETHERION WCS — серверный RPG-мод для CS2 в стиле WarCraft Source / War3FT / WCS.
Игрок выбирает РАСУ (из 198), качает уровни в бою (киллы/урон/раунды), прокачивает
способности (пассивки/активки/ульты), копит голду, крутит рулетку, открывает новые
дивизионы рас по общему уровню. Цель — самобытный, "эксклюзивный" сервер с глубокой
прогрессией, гильдиями, сезонами, питомцами.

- Платформа: CS2, framework **CounterStrikeSharp (CSSharp)**, .NET 8
- Язык интерфейса: РУССКИЙ (сервер на ru-RU Windows)
- Запуск: **listen-server** (твой клиент = хост) с флагом `-insecure`

## 1. КАК ПРАВИЛЬНО ЗАПУСКАТЬ СЕРВЕР ЛОКАЛЬНО (как мы делаем сейчас)
==================================================================
ВАЖНО: Metamod/CSSharp требует `-insecure` (или `-dedicated`). Без флага — ошибка загрузки.

### Шаг 1. Собрать плагин
```
cd C:\Users\Administrator\Desktop\AETHERION-WCS
dotnet build -c Release
```
Результат: `bin\Release\net8.0\AetherionWcs.dll` (Exit 0 = ок).

### Шаг 2. Задеплоить файлы
- DLL → `...\csgo\addons\counterstrikesharp\plugins\AetherionWcs\AetherionWcs.dll`
- Расы → `configs\races.json` копировать в `...\addons\counterstrikesharp\configs\races.json`
(races.json деплоим только если меняли расы)

### Шаг 3. Перезапустить CS2 (ПОЛНЫЙ рестарт, НЕ hot-reload!)
```powershell
Stop-Process -Name cs2 -Force   # убить если запущен
& "C:\Program Files (x86)\Steam\steam.exe" -applaunch 730 -insecure +map de_dust2
```
⚠️ Hot-reload НЕ работает (виснет из-за зависимости CS2MenuManager). Только полный рестарт.

### Шаг 4. Проверить чистую загрузку (подождать ~30 сек после старта)
Лог: `...\counterstrikesharp\logs\*.txt` (последний по дате).
Ищем строку: `Finished loading plugin AETHERION WCS` — значит загрузился ОК.
Если есть error/exception — смотреть стек в логе.

### Пути (запомни — переменные сбрасываются)
- Проект: `C:\Users\Administrator\Desktop\AETHERION-WCS`
- CSSharp root: `C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\addons\counterstrikesharp`
- DLL источник: `<проект>\bin\Release\net8.0\AetherionWcs.dll`
- DLL цель: `<cssRoot>\plugins\AetherionWcs\`
- Расы: `<проект>\configs\races.json` → `<cssRoot>\configs\races.json`

## 2. УПРАВЛЕНИЕ В ИГРЕ (команды и клавиши)
==================================================================
### Чат-команды
- `!wcs` — главное меню (раса/способности/магазин/рулетка/обо мне/админ)
- `!race` — выбор расы (дивизион → раса → превью → подтверждение)
- `!bind` — меню биндов (см. ниже)
- `!spin gold` / `!spin race` — рулетка
- `!daily` — ежедневная награда (стрик)
- `!boss` / `!event` — голосование за мирового босса (PanoramaVote)
- `!duel <ник>` / `!duel accept` — дуэли (ставка голдой)
- `!ult` — каст ультимейта
- `!wisp` — питомец-дух

### Хоткеи (через !bind)
- Z = ульта · X = меню WCS · C = способность · Mouse5 = колесо · Q = назад/закрыть

### ⚠️ ВАЖНО про !bind (проверено в игре)
- Меню `!bind` имеет 2 кнопки: «⚡ ЗАБИНДИТЬ СЕЙЧАС (авто)» и «📋 ОТПРАВИТЬ БИНД В ЧАТ».
- **АВТОБИНД НЕ РАБОТАЕТ** — Valve блокирует серверу установку биндов клиенту
  (ExecuteClientCommand с "bind" игнорируется движком). Это НЕ наш баг, это защита движка.
- РАБОЧИЙ способ: кнопка «отправить в чат» → игрок копирует строки в консоль (~) вручную.
- TODO: убрать/пометить кнопку автобинда как нерабочую, оставить акцент на ручном.
  Возможная альтернатива на будущее: гайд с готовым autoexec.cfg или подсказка с одной
  строкой для вставки.

## 3. ЧТО УЖЕ СДЕЛАНО (полный список)
==================================================================
### Расы и способности
- 198 классических рас (races.json, id 2000+) из архивов War3FT/WCS
- 8 дивизионов, пороги общего уровня: [0,200,500,1000,1800,3000,4500,7000]
- 31 эффект реализован в RaceRuntime (статы, AoE, CC, телепорт, хук, лечение, призыв и т.д.)
- РАЗНООБРАЗИЕ: убраны дубли эффектов (257 замен), у рас микс типов
  Пассив(статы) / Актив(КД 18с) / Ульта(КД 35с, сильнейший боевой эффект)
- Русификация: 1077 способностей (названия+описания), 47 названий рас (теги франшиз сохранены)
  ⚠️ Часть названий рас остались смешанные RU/EN (словарь перевода неполный)

### Уровни и XP
- Кап уровня расы = 1000 (БАГ "/8" ИСПРАВЛЕН — был тировый кап 8/12/16 в LevelSystem.MaxLevelForRace и в HUD)
- XP за: киллы (+мультикиллы Дабл×1.2/Трипл×1.4/Quad×1.7/Эйс×2.0, нож, хедшот),
  урон (по разнице уровней жертвы, +4%/ур.), ассист, победа в раунде, бомба (плант/дефьюз)
- ЛИЧНЫЕ уведомления в чат на каждое действие с прогрессом XP (тек/нужно до след. уровня)
- Банк уровней ("Обо мне") — перевод накопленных уровней в текущую расу

### Меню (CS2MenuManager / WasdMenu)
- Главное, Раса(дивизион→раса→превью), Способности(апгрейд/ресет/автоапгрейд),
  Магазин(каталог, цены, редкость ⚪🔵🟣🟠🔮), Рулетка(голда/раса), Обо мне(банк, прогресс
  8 дивизионов), Админ-меню(выдача уровней), Бинды(!bind)
- ПЛАН Б по футеру: подсказки клавиш вписаны прямо в ЗАГОЛОВКИ меню
  ("… │ W/S↕ E✓ Q↩ Tab✕"), т.к. локализация футера CS2MenuManager не подхватывалась.

### События и экономика
- Эфирная Буря: 4 режима (×1.5/×2/×3 XP, лунная гравитация, берсерк), ~18% шанс на раунд
- Боссы: 4 типа (HP 3000-6500, награда 1500-3200 голды + 500-1100 XP)
- Дуэли (ставка 200 голды, победителю 400)
- Магазин с предметами и редкостью, рулетка (стабильная анимация без мерцания)
- Звуки на левелап/покупку/выбор расы (через IEngineApi.PlaySound)

### Питомец (каркас)
- Wisp: спавн, рост Bond за киллы, эволюция стадий, бонусы владельцу (эфир) — нужна доработка визуала/активок

### Прочее (каркасы, не финал)
- Гильдии (GuildSystem), сезоны, Sigil Resonance, Эфирный Разлом, Paragon — есть основа, не доведены

### Админ
- admins.json: владелец SteamID 76561198682735154 = @css/root
- Админ-меню: выдача уровней в банк (+1/5/10/25) или в текущую расу (+1/5/10)

### Приветственный бонус
- Новому игроку при первом спавне +500 голды (флаг PlayerData.WelcomeBonus,
  сохраняется в БД, выдаётся 1 раз). Сообщение в чат + подсказка !wcs.

### Меню !bind (переработано)
- 1-я кнопка «ПОЛУЧИТЬ КОМАНДЫ В ЧАТ» (рабочий способ) — выдаёт готовую строку:
  bind z css_z; bind x css_wcs; bind c css_c; bind mouse5 css_wheel; bind q css_back
- 2-я кнопка «Попробовать авто» помечена как «может не сработать»
  (АВТОБИНД блокируется движком Valve — это НЕ баг, ручной способ рабочий).
- Меню висит 60 сек.

## 7. ТЕХНИЧЕСКИЕ ДЕТАЛИ (грабли, которые мы прошли)
==================================================================
- CounterStrikeSharp.API 1.0.362 (рантайм 1.0.369, build API 1.0.305), CS2MenuManager 1.0.42, net8.0
- ⚠️ Если в AetherionPlugin.cs вызывается метод, которого НЕТ — проект НЕ компилируется,
  а dotnet build может отдать старый DLL → в игре будут старые баги. ВСЕГДА проверять Exit 0
  И что в логе свежее время загрузки. (Так было с OpenBindMenu — отсюда "ложный" баг HUD "/8".)
- Поля моделей: RaceProgress.UnspentPoints (НЕ SkillPoints); RaceTier enum = Mythic (НЕ T5_Mythic)
- AbilityDef JSON-ключи: n(имя)/t(тип)/max/d(описание)/effect/value/cd
  Типы t: "Passive" / "Active" / "Ultimate"
- Эффекты делятся: PASSIVE(статы) vs TRIGGER(активки/ульты) — см. трансформер русификации
- Меню API: new WasdMenu("Заголовок", this); menu.AddItem("текст", (pl,o)=>...);
  menu.AddItem("текст", DisableOption.DisableHideNumber) для не-кликабельных; menu.Display(p, секунды)
- SQLite требует e_sqlite3.dll в папке плагина
- EyeAngles раньше падал (несовпадение API) — после апгрейда API ок
- Сервер на ru-RU → CS2MenuManager ищет ru.json (а не en.json) для локализации
