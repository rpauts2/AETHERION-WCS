# D1 Rebalance Plan — AETHERION-WCS
Дата: 2026-06-27

## Проблемы текущего D1
- 25 рас, из которых 8+ дублируют базовые эффекты: bonus_hp + low_gravity + speed_buff/invisibility.
- Шаблонные наборы не дают смысла выбирать между Fox/SC2:Colossus/SC:Marine.
- HP-бонус +40 у 5 рас — делает D1 слишком “танковым” и монотонным.
- Нет ролевых различий: нет чистой поддержки, нет assassin, нет контроллера.
- Нет AETHERION-уникальных рас — только наследие Warcraft/StarCraft/Dota.

## Цель D1
- 40-50 рас в D1.
- 4 архетипа: Assault / Support / Assassin / Tank.
- Каждая раса должна читаться как “второе имя” с первого взгляда.
- Ульты простые, но эмоциональные: вспышка AoE, щит, прыжок, быстрый контроль.
- Пассивные бонусы точечные, не всеобщие +HP/+speed/+invisibility.

## Новые эффекты, которые нужно добавить
- `regen_hp` — реген в бою (PR).
