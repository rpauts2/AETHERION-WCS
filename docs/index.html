Быстрый старт

Как запустить на своём сервере

# 1. Клонируйте репозиторий
git clone https://github.com/rpauts2/AETHERION-WCS.git

# 2. Соберите
dotnet build -c Release

# 3. Установите
cp bin/Release/net8.0/AetherionWcs.dll
    addons/counterstrikesharp/plugins/Aetherion/
cp -r configs/ addons/counterstrikesharp/configs/

# 4. Запускайте CS2
[AETHERION] Загружено рас: 200+. Плагин v0.4.0 готов.
