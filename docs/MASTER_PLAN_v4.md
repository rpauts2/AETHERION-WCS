# AETHERION-WCS — MASTER PLAN v4 (2026-06-28)
> Полная ревизия. Акцент: уникальные кастомные механики рас D1, не шаблонные Warcraft-клоны.

## Принцип проектирования рас
- Каждая D1-раса продумывается **с нуля вручную**, без копирования существующих WCS-рас.
- Нет жёсткого правила «1 пассивка + 1 активка + 1 ульта».
- У расы может быть **от 3 до 12+ навыков** в любых сочетаниях: пассивки, активки с КД, ультимейты, модификаторы оружия, aura, режимы.
- Главный критерий: **интересно играть**, механика запоминается, есть «почему я играю именно этой рассой».

### Примеры кастомных концепций
- **ПУДЖ-ТАНК**: только нож, много HP, медленный, пассивка-хук разворачивает врага спиной, ульт — массовый хук-вспышка.
- **ФЛЕШ-РАСА**: 1 HP, огромная скорость, пассивный крит/урон от бедра, активка — телепорт за спину, ульты нет (всего 2 навыка).
- **КИБЕР-СНАЙПЕР**: только AWP/Скауты, пассивный сквозной урон, активка — сканирование/подсветка врагов, ульта — ONE-SHOT выстрел по координатам.
- **ДУХ-ЭФИРА**: нет оружия, только способности, пассивка —吸血 по AoE, активка — параличная сеть, ульта — призыв мини-вспомогательного духа.
- **ВРЕМЯНЩИК**: пассивка — откат способностей ускоряется со временем, активка — заморозка времени в радиусе, ульта — перемотка собственного состояния (возврат HP/позиции 3 сек назад).
- **ЭВОЛЮЦИОНИСТ**: набирает стадии в течение жизни/раунда, каждая стадия открывает новый навык и меняет модель/эффект.
- **ПУСТОТНИК**: пассивка —DamageReflect + инвис после получения урона, активка — черная дыра, ульта — телепортация + цепной молния.
- **ТОРГОВЕЦ**: нет прямого урона, пассивка — золото на урон, активка — продажа HP за золото, ульта — массовый бафф союзников за счёт собственного HP.
