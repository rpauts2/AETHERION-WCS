### 3.2 Эксклюзивные фичи (уникальные vs конкурентов)
**Гильдии:**
- Пассивные бонусы гильдии (увеличение урона/хила/опыта всем членам)
- Совместный прогресс (гильдейский уровень, общий даркпасс)
- Система крафта (обмен ресурсами внутри гильдии)
- Турниры между гильдиями (еженедельные бои за призы)

**Сезоны:**
- Сезонные маппинги (смена карты/погоды каждый сезон)
- Сезонные бонусы (активные только в определённый сезон)
- Сезонная валюта для покупки эксклюзивных предметов

**Paragon:**
- Престиж-уровни (после макс. уровня)
- Уникальные ауры Paragon (визуальные эффекты)
- Кастомные анимации ультимейтов для Paragon

**Питомцы-компаньоны:**
- Боевые питомцы с собственными способностями
- Эволюция питомцев (улучшение при прокачке)
- Синхронизация навыков питомца с расой владельца

**Competitive-лестница:**
- Ранговые сезоны (Bronze/Silver/Gold/Platinum)
- Лидерборды
- Награды за ранг (скины, титулы, эффекты)

## 4. Долгосрочные задачи (1-2 недели)

### 4.1 3 прорывные идеи из аудита CS2
1. **Subtick-безопасный цикл событий для CombatEffects**
   - Текущий: урон применяется в основном потоке
   - Цель: отложить ApplyDamage на конец тика, избежать гонок
   - Способ: через `NativeAPI.CreateTask` + очередь в `CombatEffects`

2. **Типизированная обёртка для Panorama-голосований**
   - Wrapper-класс `PanoramaVoteBridge`
   - Типизированные опции (VoteOption<T>)
   - Fallback на нетки-голосование

3. **Hot-reload устойчивая рантайм-оболочка**
   - Сохранить состояние (игроки, HP, баффы, Inventory) в snapshot
   - При перезагрузке плагина восстановить состояние
   - Без потери данных при `/reload`

### 4.2 Доработка боевой системы
- `CombatEffects.cs`: адаптивный кап урона по HP цели с регеном/хилом в рамках тика, без несуществующего `GetMaxHealth`
- Vengeance-style reflection для рас с `damage_reflect`
- Conditional buffs (например, +урон ночью, +скорость в воздухе)
- Chain lightning с правильным таргетингом

### 4.3 Тестовый запуск на CS2
- Деплой `AetherionWcs.dll` + `configs/` + `lang/` в CS2 сервер
- Проверка загрузки плагина через `sm_plugins list`
- Тест русских строк в чате/меню
- Балансовый тест: зайти за каждую расу D1, проверить навыки
