## 1. 🎰 Анимированная Рулетка Эфира — `src/Plugins/AetherRoulette.cs`
**Проблема:** в CS2 нет нативных меню и анимаций; почти все рулетки = статичный текст.
**Решение:** покадровый рендер center-HTML как «крутящийся барабан»:
- лента из 9 ячеек, центр — указатель ▼;
- честный выбор приза ПО ВЕСАМ заранее, лента строится так, чтобы winner встал под указатель;
- физика замедления **ease-out** (нарастающая пауза между кадрами) — барабан реально «тормозит»;
- финальная вспышка + цвет по редкости (Обычный→Мифик), выдача приза.
**Статус:** ✅ код готов. Типы рулеток: Золото / Раса / Донат.

## 2. 🛡️ Система гильдий с живыми бафами — `src/Systems/GuildSystem.cs`
- Общая казна, Знамя гильдии (совместный апгрейд, квадратичный XP-кривой);
- бафы на ВСЕХ членов: +золото/+опыт за уровень знамени, растущий лимит состава;
- **гильд-расы усиливаются от числа согильдийцев онлайн** (+4%/чел, кап +40%);
- топ гильдий по знамени, наследование лидерства.
**Статус:** ✅ код готов.

## 5. 🌌 AETHER NEXUS — диегетический 3D-интерфейс (ФЛАГМАН) — `src/Plugins/AetherNexus.cs`
**Самая масштабная фишка. Первый в CS2 «UI, встроенный в мир игры».**

**В чём суть:** в CS2 нет нативного UI-API (вырезан из CS:GO). Все делают плоский
текст. Мы пошли дальше — построили **персональный 3D-зал вокруг игрока** из
`point_worldtext`-сущностей. Это не меню «на экране», а интерфейс В МИРЕ (как в VR).

**Как работает:**
- игрок открывает Nexus → вокруг него дугой спавнятся светящиеся 3D-узлы;
- **навигация взглядом**: узел под прицелом подсвечивается (цвет + размер шрифта),
  расчёт по dot-произведению вектора взгляда и направления на узел;
- выбор по клавише **E** (+use);
- узлы — это «порталы» в секторы: 🧬 Расы, 🛒 Магазин, 🎰 Рулетка, 🛡️ Гильдия, 🏆 Сезон;
- каждый сектор наполняется через провайдеры (`RacesProvider`, `ShopProvider` и т.д.),
  так что контент динамический (открытые расы, цены, состав гильдии);
- «волна» по высоте узлов даёт объём; цвета — фирменный эфирный фиолетовый.

**Почему это важно:** рулетка, голо-меню рас, магазин — больше не разрозненные
команды, а **секторы единого Nexus**. Единый язык интерфейса, погружение, вау-эффект.

**Статус:** ✅ ядро готово. Дальше: beam-порталы между секторами, particle-ауры узлов,
анимация «разворачивания» зала при открытии.

### 📐 Техническая честность
- Всё построено на **официальных сущностях движка** (`point_worldtext`), не на хаках.
- Ограничение CS2 (нет UI-API) — реальное, но обходится рендером в мире.
- Координаты узлов требуют обкатки на разных картах (привязка к позиции/взгляду игрока — уже сделана динамически).

## 📦 ОБНОВЛЕНИЕ: Магазин + полная интеграция Nexus

### 🛒 ITEM SHOP — `src/Systems/ItemShop.cs`
Магазин предметов за золото (в духе старых WCS), сбалансированный (анти-P2W):

### 🔗 NEXUS INTEGRATION — `src/Core/NexusIntegration.cs`
Nexus теперь живая система, а не заготовка:
- **Провайдер РАС** — показывает открытые/закрытые расы дивизиона, выбор = смена расы;
- **Провайдер МАГАЗИНА** — покупка предметов прямо из 3D-зала (узлы тускнеют, если не хватает золота);
- **Провайдер ГИЛЬДИИ** — тег, уровень Знамени, казна;
- **Провайдер СЕЗОНА** — ранг и сезонный XP;
- **Рулетка** — крутится из сектора Nexus;
- **Хук E (+use)** через OnTick: ловим момент нажатия (edge-detection) → `Confirm()`.

### ✅ Что теперь работает end-to-end
1. Игрок пишет `!nexus` → вокруг него разворачивается 3D-зал;
2. смотрит на сектор (🧬🛒🎰🛡️🏆) → подсветка → E → проваливается внутрь;
3. в Расах — выбирает разблокированную расу взглядом;
4. в Магазине — покупает предметы за золото с киллов;
5. в Рулетке — крутит анимированный барабан;
6. всё сохраняется в SQLite.

## 6. ⚔️ CS2 ENGINE API — реальный боевой движок — `src/Systems/Cs2EngineApi.cs`
Единая точка интеграции с CounterStrikeSharp. Реальные вызовы:
- HP (SetHealth/AddHealth через m_iHealth + SetStateChanged);
- скорость (m_flVelocityModifier), гравитация (m_flGravityScale);
- телепорт, отбрасывание (Knockback по вектору от источника);
- поджог, невидимость (m_clrRender alpha=0), beam-лучи (env_beam), частицы (info_particle_system), звук.
Все навыки рас и печати дёргают этот API. **Статус:** ✅ готов.

## 7. ✨ ЭФИРНЫЕ ПЕЧАТИ — заклинания через ЖЕСТЫ — `src/Plugins/AetherSigils.cs`
**ПЕРВОЕ на CS2. Самая хардкорная механика мода.**
Игрок «рисует» печать последовательностью движений взгляда (↑↓←→), как паттерн-замок:
- зажал спец-клавишу → крутит мышь → жесты распознаются по дельте yaw/pitch (порог 12°);
- совпал паттерн → каст мощного комбо; не совпал → фейл;
- **скилл руками, а не просто кулдаун** — высокий скилл-кап как у файтингов/MOBA.

**Печати:**
| Печать | Жест | Эфир | Эффект |
|--------|------|------|--------|
| ⚡ Громовая Дуга | ←↑→ | 50 | цепная молния перед игроком |
| ➤ Эфирный Рывок | ↓↑ | 35 | мгновенный рывок по взгляду |
| ◐ Купол Эфира | ←↓→↑ | 70 | защитный купол + хил |
| ✸ Зов Бездны | ↑↑↓↓←→ | 120 | мифик: взрыв тьмы, массовый урон |

**Почему вау:** никто на CS2 не делал «жестовый» каст. Это про мастерство, а не про P2W.
**Статус:** ✅ код готов (распознавание жестов по дельте взгляда в OnTick-таймере).

## 8. 🔗 БОЕВАЯ ПРИВЯЗКА РАС — `src/Races/RaceRuntime.cs`
Навыки рас теперь РЕАЛЬНО работают через движок (не просто описания):
- **EffectLibrary** — библиотека эффектов по тегам (bonus_hp, speed_buff, low_gravity,
  regen, heal_self, dash_forward, invisibility, lightning_strike, aoe_explosion,
  lifesteal, soul_collect, teleport_spawn);
- **RaceRuntime** — применяет пассивки при спавне и активирует ульты/активки;
- data-driven: тысячи рас работают БЕЗ тысяч классов — навык ссылается на тег эффекта.

### 🔧 Унификация схемы (важный фикс)
- Привёл модель `AbilityDef` к реальным ключам JSON (n/t/d/max/cd/ether) — раньше была
  рассинхронизация, расы не десериализовались бы корректно;
- добавил поля `effect`/`value`/`Index` для связи навык↔движок;
- `RaceManager` проставляет Index способностям при загрузке.

### 📊 Покрытие эффектами
- **68/153 способностей (44%)** привязаны к реальным эффектам движка;
- остальные — числовые пассивки (бонусы статов), считаются в боевом расчёте урона/HP.

**Статус:** ✅ фундамент боёвки готов. Дальше: радиус-урон для AOE, тики поджога/регена,
длительности эффектов (снятие невидимости/баффов по таймеру).

## 9. 💫 COMBAT EFFECTS — длительности, тики, AOE — `src/Systems/CombatEffects.cs`
То, чего нет в одиночном вызове движка:
- длительные баффы/дебаффы со снятием по таймеру (невидимость, скорость, замедление, щит);

## 10. 💫 ДУХ-КОМПАНЬОН (AETHER WISP) — живой спутник — `src/Plugins/AetherWisp.cs`
**Первое на CS2. Душа мода в буквальном смысле.**
Маленький светящийся дух (point_worldtext-глиф) парит рядом с игроком:
- **плавное парение по орбите** (lerp-интерполяция + синусоидное покачивание), висит слева-сверху;
- **5 настроений** с разными «лицами» и цветами: Calm ◔◡◔ / Happy ◕‿◕ / Excited ★ω★ / Worried ◑﹏◑ / Furious ﾉಠ益ಠ;
- **реагирует на события**: килл-стрик («РАЗНОС!»), хедшот, низкое HP («может, Купол Эфира?»), смерть, мало Эфира;
- **подсказывает печати** по ситуации;
- копит **Bond (привязанность)** за сессию — основа будущих наград/эволюции духа;
- антиспам реплик (не чаще раза в 2.5 сек).

**Почему вау:** это не HUD, а персонаж-спутник. Эмоциональная привязка, которой нет ни у кого на CS2.
**Статус:** ✅ код готов. Дальше: эволюция духа по Bond, кастомные скины, голосовые наборы.

## 11. ⚙️ ПОЛНАЯ ИНТЕГРАЦИЯ В ЯДРО — `src/Core/AetherionPlugin.cs`
Все системы теперь связаны и работают через события:
- **OnSpawn** → RaceRuntime применяет пассивки расы (HP/скорость/гравитация/реген) + чистка эффектов;
- **OnDeath** → Wisp реагирует (стрик/хедшот атакера, утешение жертвы) + XP/золото/Эфир/гильд-фраг;
- **OnTick** → CombatEffects.TickAll (поджог/реген/снятие баффов);
- **CmdUlt** → реальная активация ульты через RaceRuntime + AOE-урон (для площадных) + длит. эффекты (невидимость и т.п.); стоимость Эфира берётся из навыка;
- новые команды: `!sigil`/`!cast` (печати жестами), `!wisp` (призыв духа).

### 🎮 Что работает end-to-end ТЕПЕРЬ
1. Спавн → пассивки расы реально применяются к игроку;
2. Килл → Эфир растёт, дух реагирует эмоцией, стрики считаются;
3. `!ult` → ультимейт бьёт по площади / накладывает невидимость / лечит — через движок;
4. `!sigil` → рисуешь печать мышью → `!cast` → заклинание срабатывает;
5. `!nexus` → 3D-зал: выбор расы, магазин, рулетка;
6. поджог/реген тикают, баффы спадают по времени.

**Статус:** ✅ вертикальный срез геймплея собран. Мод играбелен по ядру.

## 13. 🐣 ЭВОЛЮЦИЯ ДУХА — питомец, что растёт — `src/Plugins/WispEvolution.cs`
**Тамагочи встречает WCS.** Дух копит Bond (привязанность) за килы и ЭВОЛЮЦИОНИРУЕТ:
| Ступень | Bond | Форма | Сила |
|---------|------|-------|------|
| 1 Искорка | 0 | ◔◡◔ | подсказывает печати |
| 2 Светлячок | 50 | ◕‿◕ | +5% Эфир |
| 3 Дух-Хранитель | 200 | ✦ω✦ | +10% Эфир, предупреждение о враге за спиной |
| 4 Эфирный Феникс | 600 | 🔥ω🔥 | +15% Эфир, +20 HP, подсветка союзников |
| 5 Аватар Бури | 1500 | ⚡Θ⚡ | +20% Эфир, -10% КД печатей, авто-Купол при смерти |
- Bond сохраняется в SQLite (`PlayerData.WispBond`) — дух помнит игрока между сессиями;
- хедшоты дают +2 Bond (крепче сближают);
- при эволюции — анонс, смена облика/имени/ауры, новая пассивка владельцу.
**Статус:** ✅ готов, подключён (RestoreBond при призыве, синхронизация при килле).

### 🎯 Синергия систем
Эфир (ресурс) → Печати (жесты) → Резонанс (комбо) → Дух (бусты Эфира/КД) → больше печатей.
Замкнутый «dopamine loop» мастерства, которого нет ни у кого на CS2.
