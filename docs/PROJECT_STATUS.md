## 🔗 ГЛАВНАЯ СИНЕРГИЯ (dopamine loop мастерства)
```
Эфир (ресурс за килы) → Печати (жесты мышью) → Резонанс (комбо)
   → Дух-компаньон (бусты Эфира/КД, растёт по Bond) → больше печатей
```
Плюс классический WCS-цикл: килл → XP+золото → новый уровень → общий уровень
→ открытие новой расы → «ещё одна раса».

## ✅ ЧТО РАБОТАЕТ END-TO-END
1. Спавн → пассивки расы применяются реально (HP/скорость/реген)
2. Килл → Эфир (+бонус формы духа), золото, XP, дух реагирует эмоцией, гильд-фраг
3. `!ult` → ультимейт бьёт через движок (AOE/невидимость/хил)
4. `!sigil` → рисуешь печать → `!cast` → срабатывает; 2 подряд → резонанс-комбо
5. `!nexus` → 3D-зал: выбор расы, магазин, рулетка
6. `!wisp` → призыв духа, помнит Bond между сессиями, эволюционирует
7. Поджог/реген тикают, баффы спадают; всё сохраняется в SQLite
