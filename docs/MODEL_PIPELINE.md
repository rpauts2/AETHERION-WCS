## 📋 ЧТО ПОСТАВИТЬ (тебе, бро)
1. **CS2 Workshop Tools** — Steam → Библиотека → CS2 → ПКМ → Свойства → DLC →
   галочка **"Counter-Strike 2 Workshop Tools"** (~15 ГБ). Появится `game/bin/win64/resourcecompiler.exe`.
2. **Blender** (бесплатно) — blender.org/download (для Уровня 2: меши/аксессуары).
   Для Уровня 1 (реткстур) Blender НЕ обязателен.

Скажи мне, когда поставишь — я перепроверю и запущу пайплайн.

## 🎯 3 УРОВНЯ КАСТОМИЗАЦИИ

### Уровень 1 — РЕТКСТУР (без Blender, сразу 🔥)
Берём базовый CS2-скелетон → кастомный материал из концепт-арта:
- свечение/эмиссия Эфира, руны, цвет ауры по дивизиону
- D1 белый · D2 оранжевый · D3 синий · D∞ фиолетово-золотой
Каждая раса визуально отличается. Меш не меняем → 100% совместимость.

### Уровень 2 — МЕШ-МОДИФИКАЦИЯ (нужен Blender)
- CC0-база (Quaternius/Sketchfab CC0) или базовый меш
- приделать крылья/рога/оружие, скульпт деталей
- текстуры из концепт-артов (уже есть 9 артов)
- экспорт .fbx → компиляция → .vmdl

### Уровень 3 — честный лимит ⚠️
AAA-скульпт с нуля — ручная работа 3D-художника. Я выдам «круто», не «студийно».

## ⚙️ ПОТОК ДАННЫХ (автоматизировано)
```
концепт-арт (есть)
  → текстура _color/_normal/_rough  [скрипт generate_textures]
  → материал .vmat                  [шаблон ниже]
  → модель .vmdl                    [resourcecompiler]
  → запись в configs/assets/models.json (customModel)  [авто]
  → precache + SetModel в игре      [уже работает в коде]
```
