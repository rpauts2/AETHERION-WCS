# ⚡ AETHERION — Эксклюзивные плагины (то, чего ещё НЕ было)

Цель: каждый плагин — «вау», чтобы игроки шли именно к нам.
Где CounterStrikeSharp не позволяет нативно — решаем обходом (см. «Реализация»).

## 1. 🎴 МЕНЮ «AETHER HUD» — меню, которое разрывает
**Проблема:** в CS2 нет нормального кастомного UI как в Source 1 (VGUI).
CSSharp даёт только center-text/chat + ограниченный HTML.

**Решение (инновация):**
- **HTML-оверлей через CenterHtml + спрайт-иконки** — рисуем «карточки рас» псевдографикой
  и Unicode-иконками (▰▰▰ прогресс-бары, ★ тиры, ⚡ Эфир).
- **Радиальное меню на цифрах 1-9** с живым превью: при наведении показываем
  лор+навыки расы в center-html в реальном времени.
- **Анимация Эфира:** полоска ресурса пульсирует (обновление каждые 100мс).
- **Звук при выборе** (см. sounds) — тактильный фидбэк, которого нет у конкурентов.
- **Фаза 2:** полноценный WebUI через встроенный HTTP-сервер плагина +
  кнопка «!panel» открывает в Steam-оверлее браузер с красивым React-интерфейсом
  (профиль, расы, рулетки, гильдия) — синхронизация по SteamID.

## 2. 🎰 РУЛЕТКА «ETHER WHEEL» — гэмблинг с душой
- Анимация прокрутки прямо в center-html (бегущая строка призов с замедлением).
- **Честные шансы видны** + пити-гарант (анти-фрустрация).
- 4 колеса: Золото / Приват-раса / Донат / Общая.
- **Эксклюзив:** «Колесо Судьбы Гильдии» — крутит вся гильдия в складчину,
  приз падает случайному активному участнику (социальный гэмблинг).
- Звук барабана + фанфары на джекпот.

## 3. 🛡️ АДМИНКА «AETHER COMMAND» — креативная модерация
**Не банальный !ban/!kick, а «режиссёрский пульт»:**
- **Live-дашборд** (HTTP-панель): список игроков, их расы, уровни, подозрительная статистика.
- **«Дух наблюдателя»** — админ входит в режим невидимого духа с телепортом к любому игроку,
  подсветкой действий, мгновенным замером KD/точности (анти-чит помощник).
- **Быстрые действия по цифрам** в радиальном меню над игроком в прицеле.
- **Тихий мут/слоумод чата**, временная «клетка Эфира» (заморозка читера до решения).
- Логи всех действий в Discord-вебхук.

## 4. 💎 VIP «PROBUZHDENNYY+» — статус, а не pay-to-win
- **Косметика:** свечение ника, кастомный цвет, эфирный трейл за игроком, особый звук килла.
- **Удобства:** +25% золота/XP-буст (НЕ урон!), доступ к ранней очереди рулетки.
- **Эксклюзив-косметика рас:** уникальные частицы ультимейтов для VIP.
- **«Тронный зал»** — VIP-лобби между картами с лидербордом.
- Принцип: VIP даёт СТАТУС и КОМФОРТ, но не ломает баланс.

## 5. 🏰 ГИЛЬДИИ «ORDENA» — социальный движок
- Создание/вступление через !guild, общий банк золота, гильд-расы.
- **Гильдейские войны:** недельный зачёт фрагов между гильдиями, топ получает баннер на сервере.
- **Гильд-рейды (PvE):** между PvP-раундами волна ботов, гильдия фармит вместе.
- Гильд-чат, теги [TAG] перед ником с цветом гильдии.

## 6. 🏆 СЕЗОНЫ + BATTLE PASS «ASCENSION»
- Сезон 4-6 недель: сезонный ранг, новые расы-новинки, баланс-патч меты.
- Battle Pass: уровни дают КОСМЕТИКУ (титулы, трейлы, цвета) — не силу.
- Сезонный лидерборд «Кто первый добил легендарную расу».

## 7. 🔥 ФИШКИ-«КИЛЛЕРЫ» (чего нет ни у кого)
- **Эфирные События на карте:** случайно появляется «Разлом Эфира» — кто захватит,
  получает временный бафф всей команде (динамика + командная драка за точку).
- **Расы-конструкторы (D∞):** топ-игрок собирает свою ульту из 5 модулей.
- **Кросс-карта прогресс-цели:** сервер-ивенты «убить 10000 врагов всем сервером
  за выходные» → общая награда всем.
- **Голос Эфира:** ИИ-диктор (озвучка) комментирует эпичные моменты (тройной килл и т.п.).

## РЕАЛИЗАЦИЯ ограничений CS2/CSSharp
| Хочу | Ограничение | Решение |
|------|-------------|---------|
| Богатый UI | нет VGUI | center-html + спрайты + внешняя WebUI через HTTP-сервер плагина + Steam overlay |
| Кастом-модели | ограниченная поддержка | замена через precache + SetModel на разрешённые, либо скины-частицы/glow вместо моделей |
| Кастом-звуки | нужен addon на клиенте | использовать встроенные soundevents + серверный workshop-addon |
| Сложная физика | частично | серверная симуляция (тики), VelocityModifier, Teleport |
| Внешняя панель | нет нативно | ASP.NET-мини-сервер внутри плагина + JWT по SteamID |
