# WCS-серверы: что было и что они дали рынку
Дата: 2026-06-27

## Сummary публичных данных

### Известные проекты / аналоги
- **Мир Героев / playwcs.ru** — самая известная русскоязычная сеть WCS.
- **Black Star / StarServ** — ещё один известный формат WCS-серверов в рунете.
- **CrazyStar WCS** — избыток рас, гибридные моды.
- **DivineWCS2.ru** — WCS2 CS2, коммерческая VIP-модель.
- **War3CS2 (C# / CSSharp)** — 326+ рас, diminishing-buffs, 50 предметов.
- **ThaPwned/WCS (Python / Source.Python)** — актуальный до 2022, legacy EventScripts.

### Баланс-паттерны
- Кап уровня расы 1000, 8 дивизионов.
- Формула XP: `(lvl+1)*300` + бонусы за кил, урон, раунды.
- Снижающиеся баффы (diminishing buffs), weapon-fire-rate scaling.
- Экономика: за килл/хедшот/нож/ассист/бомбу/раунд.

### Что обычно отсутствует у конкурентов
- Нет публично наблюдаемых гильдий, сезонов, Paragon/Prestige, питомцев-компаньонов, matchmade лидербордов, unified cross-server профиля.
- Нет публичной balance transparency.
