## 🎯 СТРАТЕГИЧЕСКАЯ ЦЕЛЬ
Превратить AETHERION-WCS в **первую полноценную социальную WCS-платформу на Source 2**:
глубокая прогрессия рас + уникальные механики (Печати, Дух-эволюция, Разлом) +

## ФАЗА 0 — СТАБИЛИЗАЦИЯ ФУНДАМЕНТА (ПРИОРИТЕТ #1)
> Без этого любые новые фичи бесполезны — сервер не соберётся/не запустится.

### 0.1 Восстановить главный плагин (КРИТИЧНО)
**Проблема:** `AetherionPlugin.cs` — заглушка, все методы `{ }`.
**Решение:** Написать полный плагин-интегратор, сшивающий все системы:
- `Load()`: загрузка races.json, models, audio, SQLite, регистрация ВСЕХ команд (`!wcs !race !ult !spin !daily !guild !boss !duel !wisp !sigil !cast`)
- Хуки событий: `OnSpawn` (применить пассивки+модель+корону), `OnDeath` (XP+голда+дух+ачивки+сервер-статы), `OnHurt` (проки пассивок), `OnRoundStart/End` (сезонный XP, стрики), `OnBomb*`
- Тики: `RiftTick` (0.5с), `EtherRegen` (1с), `CombatEffects.TickAll`, `BossTick`, `HudTick`, `WispTick`
- Меню: `OpenMainMenu`, `OpenRaceMenu`, `OpenSkillMenu`, `OpenShopMenu`, `OpenAboutMenu`, `OpenAdminMenu`, `OpenBindMenu`, `OpenGuildMenu`, `OpenVipMenu`, `OpenAchievementsMenu`, `OpenBattlePassMenu`

### 0.2 Решить рассинхрон рас
- Выбрать канон: **объединить** races.json (25 «новых» с эффектами) + races_core.json (110 «продуманных») → единый `races_master.json`
- Унифицировать ID-пространство (рекомендация: 2000+ для всех, как в активном)
- Синхронизировать `models.json` под канон
- Удалить/архивировать дубли

### 0.3 Починить дублирующие ключи в RaceRuntime.Effects
- `invisibility`, `blink`, `execute`, `execute_bonus`, `execute_ult`, `chase_speed`, `armor_reduce`, `parry` определены дважды → словарь перезаписывает
- Решение: алиасы вынести в отдельный слой (Resolve() проверяет основной словарь, потом алиасы)

### 0.4 Обернуть рискованные вызовы
- `AetherRiftEvent.SpawnParticle` → try/catch + fallback
- `AudioManager` → fallback-логи если звук не найден
- `Guild.Leave` → починить очистку Officers

## ФАЗА 1 — РАСЫ: КАЧЕСТВО И БАЛАНС (ПРИОРИТЕТ #2)
> «Сделай расы интересными, каждую вручную, чтобы игрокам нравилось»

### 1.1 Ребаланс существующих рас (D1-D∞)
**Методология баланса** (вдохновлено War3CS2 diminishing-buffs):
- **HP-бюджет по дивизиону:** D1 +8-12/ур (≈+96-144 к кап), D2 +10-15, D3 +12-18, D∞ +14-22
- **Урон-бюджет:** D1 +3-4%/ур, D2 +4-5%, D3 +5-7%, D∞ +6-10%
- **Каждая раса = 1 уникальная фишка**, не повторяющаяся в дивизионе
- **Ульты:** D1 слабые (хил/побег), D3 мощные (AOE-казнь), D∞ трансформационные

**Действия по дивизионам:**
- **D1 Искра (30→45 рас):** каждый архетип (tank/support/assassin/duelist/mage/mobility) представлен 5+ расами. Убрать «скучные» (только статы).
- **D2 Пламя (22→35 рас):** добавить комбо-синергии, расы с 2+ активками.
- **D3 Шторм (20→30 рас):** power-fantasy, узкие ниши (PVE-босс-киллер, 1v5-чистер).
- **D∞ Вечность (10→15 рас):** god-tier конструкторы (Аватар Эфира, Хронарх).
- **Гильд-расы (8→12):** сила зависит от активности гильдии.
- **Сезонные эксклюзивы (0→8):** ротация каждый сезон.
- **Мемы (0→6):** Курица-нинзя, Гном-минёр (как у Мир Героев).

### 1.2 Защита от «скучных» рас
Каждая раса проверяется по чеклисту:
- [ ] Минимум 1 активка (Z/C) или ульта (X)
- [ ] Уникальный эффект в дивизионе
- [ ] Читаемая фишка с первого взгляда
- [ ] Лор в 1 предложении (как «Эфир научил его пить чужую жизнь»)

### 1.3 Кастомное оружие и ограничения (НОВОЕ)
- **Расы с ограничением оружия** (как Дуэлянт Искры = только Deagle):
  - Палач Дуэлей → только Deagle, но +урон и ∞ патроны
  - Дуэлянт → только нож/пистолет
  - Снайпер-Призрак → только AWP/Scout
- **Кастом-оружие:** у топ-рас (Жнец → коса, Архимаг → посох, Хронолог → посох времени) — визуальные модели оружия (prop_*, parented)
- Реализация: в `RaceDefinition` поле `weaponRestriction` (allowlist) + `weaponOverride` (кастом-модель), обработка в OnSpawn (RemoveAllWeapons + GiveItem)

## ✨ «ДУША» СЕРВЕРА (что сделает его неповторимым)

1. **Дух-компаньон Wisp** — тамагочи, что помнит игрока между сессиями, эволюционирует, говорит. Эмоциональная привязка.
2. **Печати жестами мыши** — каст заклинаний рисованием ↑↓←→. Нет ни у одного WCS.
3. **Эфирная Буря** — глобальные ивенты (×2 XP, лунная гравитация, берсерк) создают синие/золотые часы.
4. **Гильд-расы** — сила растёт с активностью гильдии. Социальный клей.
5. **Paragon-ауры** — короны Эфира над головой по дивизионам. Визуальный статус.
6. **Лор «Aether Storm»** — собственная вселенная, не копирайт. Мир Пробуждённых.

**Мантра:** *Каждая раса, звук, партикл и система — с душой. Качество > скорость.*
