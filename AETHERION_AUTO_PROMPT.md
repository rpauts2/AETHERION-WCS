## 2. ПРОЕКТ
Рабочая папка: C:\Users\Administrator\Desktop\AETHERION-WCS
Сборка: dotnet build -c Release
Деплой: bin/Release/net8.0/AetherionWcs.dll → CS2 addons/counterstrikesharp/plugins/AetherionWcs/

Контекст уже известен:
- Проект собирается под CS2 через CounterStrikeSharp.
- В configs/races.json сейчас 25 D1 рас (id 2000–2024), формат необёрнутого массива [...], RaceManager это поддерживает.
- RaceDefinition содержит: id, name, lore, archetype, tier, division, unlock, guild, abilities.
- AbilityDef содержит: n, d, t, max, cd, ether, effect, value + доп. поля вроде radius, duration, distance, freeze, stun, slow и т.п.
- RaceRuntime.cs — главный движок способностей, там уже есть библиотека известных Effect-тегов. Ты обязан сначала смотреть, что уже реализовано, и использовать это, а не выдумывать новые эффекты.
- У тебя уже есть готовые заготовки 25 концепций рас и механик в docs/MASTER_PLAN_v4.md и configs/races.json.

## 4. АКТУАЛЬНЫЕ ИЗВЕСТНЫЕ ОШИБКИ И ОГРАНИЧЕНИЯ

Из последней сборки:
- BossSystem.cs: ошибки с ITimer.Kill(), ITimer.IsValid, неоднозначность Timer. Уже начата временная заглушка, но система должна быть либо корректно переписана под актуальный CounterStrikeSharp API, либо полноценно убрана из сборки до отдельного рефакторинга. Нельзя оставлять код, который ломает сборку.
- RaceRuntime.cs: есть предупреждение CS0642 на строке 665 — возможный пустой оператор, требуется проверка и фикс.
- Много nullable-предупреждений в ItemShop, AetherionPlugin, LocalizationShim, LevelSystem — их не обязательно исправлять все в первую очередь, но случаи, где это приводит кNullReferenceException, должны быть устранены.
- Концептуально: RaceManager поддерживает необёрнутый races.json — значит не нужно менять формат обратно на { "races": [...] }.
